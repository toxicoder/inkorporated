# Mission, vision & values

**What's on this page**

- Inkorporated mission and vision statements (template-ready)
- Operating values that drive hiring, review, and agent behavior
- How values map to engineering principles and code of conduct

**What this enables**

- Shared north star for humans and cyborgs
- Consistent prioritization language across GTM and product

## Mission

Build and operate a complete, open, production-grade enterprise operating system—from hybrid infrastructure to org design—so ambitious teams can run like a global company without starting from zero.

## Vision

A world where spinning up trustworthy infrastructure, disciplined engineering, and coherent corporate governance is as declarative as Infrastructure as Code.

## Values

1. **Customer obsession** — Start with the user and work backwards.
2. **Ownership** — You build it, you run it; no bystander effect.
3. **Bias for action** — Prefer reversible decisions made quickly.
4. **High bar for talent** — Raise the average with every hire.
5. **Earn trust** — Security, privacy, and honesty are non-negotiable.
6. **Invent and simplify** — Automation and clarity over ceremony.
7. **Frugality with impact** — Spend where it compounds; cut theater.
